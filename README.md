# Flight Simulator 2026

Prototype de conception pour un simulateur d'avion avancé.

## Vision
Construire un jeu de simulation aérienne moderne, accessible et profond, avec :
- un modèle de vol crédible (arcade assisté + simulation complète),
- une météo dynamique mondiale,
- une carrière pilote avec progression,
- une forte immersion cockpit.

## Démarrage
Ce dépôt démarre par une phase de **game design**.

- Lire la vision complète : `docs/flight-simulator-2026-design.md`
- Lire le plan d'exécution : `docs/roadmap.md`

## Prochaine étape immédiate
Créer un **vertical slice** jouable comprenant :
1. un avion d'entraînement,
2. un aéroport,
3. un cycle météo simplifié,
4. une mission tutorielle,
5. une boucle décollage -> navigation -> atterrissage.
